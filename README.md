# SFML Starter Project

### Easily install and get started with SFML, without too much the headache of a setup

## Steps to begin:

Want a video tutorial? Watch it here: https://youtu.be/[insert_id_here]

1. If you are on Linux, run `sudo apt install build-essentials libsfml` and skip to step 5. 
1. Download [WinLibs](https://github.com/brechtsanders/winlibs_mingw/releases/download/14.2.0posix-19.1.1-12.0.0-ucrt-r2/winlibs-x86_64-posix-seh-gcc-14.2.0-mingw-w64ucrt-12.0.0-r2.7z) and [MinGW SFML](https://www.sfml-dev.org/files/SFML-3.1.0-windows-gcc-14.2.0-mingw-64-bit.zip) from the [SFML website](https://www.sfml-dev.org/download/sfml/3.1.0).
1. Extract the contents of both to `C:\` and rename `SFML-3.1.0` folder to exactly `SFML`.
1. Add `C:\SFML\bin` and `C:\mingw64\bin` to `PATH` OR run `setup.bat` after cloning this.
1. Clone this repo (Download the zip and extract or clone using `git clone`).
1. Open VSCode on the folder extracted in last step and write a basic SFML app in `main.cpp`.
1. Press `CTRL + SHIFT + B` to compile and run!
